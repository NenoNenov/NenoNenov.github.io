# Neno Nenov – Developer Portfolio

Personal portfolio built with **C# and Blazor WebAssembly**, hosted on GitHub Pages.

Live: https://nenonenov.github.io

## Editing content
All text, projects and certificates are in `wwwroot/data/portfolio.json`.
Edit that file, commit and push – the site rebuilds and deploys automatically.

## Run locally
```
dotnet run
```

## Tech
- .NET 10, Blazor WebAssembly (standalone)
- GitHub Actions → GitHub Pages
